# ひねり並べ — 置いてひねる立体の目並べ

立方体の面に印を置き、置いたあとに列を 1 回だけひねれる目並べ。ひねれば相手の列を崩すことも、自分の列を作ることもできる。CPU 対戦・ふたり対戦。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/hineri/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 自分の番に、空いているマスに印を 1 つ置く。
2. 置いたあと、好きな列を 1 回だけ 90° ひねってよい（ひねらなくてもよい）。
3. どれかの面で、縦・横・斜めに N 個（3×3 なら 3 つ、4×4 なら 4 つ）そろえたら勝ち。ひねって相手の列ができてしまったら相手の勝ち。

操作（タッチだけで遊べる）:

- **置く**: 空いたマスを 1 回タップで仮置き、もう 1 回タップ（または「ここに置く」）で置く
- **ひねる**: 置いたあと、マスをなぞるとその層が指について回る。半分（45°）以上で 90° 回して確定、足りなければ戻る。回さないなら「回さない」
- **視点**: 何もない所をドラッグ、または 2 本指でドラッグ。「⟲」で最初の向きに戻す

CPU 対戦（先手・後手を選べる）と、1 台でのふたり対戦。大きさは 3×3 と 4×4。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

一度開けば、オフラインでも遊べます。

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

遊びの中身（盤・ひねり・勝ちの判定・CPU）は `game.js` にあり、描画（`main.js`）から切り離してある。テスト:

```sh
node test.mjs
```

- 3D は [Three.js](https://threejs.org/)（MIT）を使用。`vendor/three.module.min.js`（r170、1 ファイルの ES module）を同梱し、ライセンスは `vendor/three.LICENSE`。
- r171 以降はビルドが 2 ファイル（three.core + three.module）に分かれたため、1 ファイルで済む r170 を使っている。
- 保存: `hineri.settings`（大きさ・先手後手・遊び方を見たか）、`hineri.stats`（CPU 戦の成績）
